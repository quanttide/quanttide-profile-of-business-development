# 量潮数据

## 定位：数据处理业务与平台的起点

量潮数据是量潮体系中最先落地、以数据为中心的业务：承接数据处理需求（如合同筛选、数据处理工程），以标准化的方式交付处理结果并管理数据。它是"处理费 + 存储费"商业模式的原始载体——qtcloud 吸收的正是这套模式并做了更低颗粒度的转化。

平台化方向：以三方体系（客户 / 执行方 / 平台方）各取所需为目标，平台的核心是信用与定价权。

## 核心目标：以数据为中心的商业模式与定价权

- 建立以数据为中心的收费方式：处理费 + 存储费，颗粒度可以低到"几毛几分处理一次数据"；
- 平台化终局：通过品牌、制度与文化塑造高信用平台，定价权是利润的根本来源；
- 标准外化：把内部标准外化，形成供应链池，外部团队可自动校验交付。

## 阶段方法：以工程流程承载

当前以 CLI 四命令承载数据处理流程：

1. `blueprint` — 需求拆解：把模糊业务变成可执行工程任务；
2. `scope` — 范围界定：划定处理范围与交付物；
3. `quotation` — 报价：生成报价单（最终版本作为合同的一部分）；
4. `delivery` — 交付验收：定义验收流程与准则。

质量回溯贯穿始终：问题归因与回溯是真实痛点，需要数据血缘与问题工单机制。

## 数据驱动：用数据找到业务结构

内部数据采集与反馈循环是短板也是方向：内部标准外化需要先有内部数据积累；数据血缘、问题可归因可回溯可改进；运营数据积累最终指导套餐设计与商业模型检验。
